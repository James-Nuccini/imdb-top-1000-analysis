
# IMDb Top 1000 Movie Analysis

This project explores IMDb’s Top 1000 Movies dataset using Microsoft Excel, Power Query, and Pivot Charts. The goal was to uncover insights across genres, decades, directors, and viewer engagement through data cleaning, transformation, and visual storytelling.

## 📁 Files Included

- **IMDb_Top_1000_Movie_Analysis_Report_James_Nuccini.docx**  
  Final project report summarizing methodology, visuals, and findings.
  
- **IMDb_Top_1000_Movie_Analysis_Cleaning_Log_James_Nuccini.docx**  
  Detailed cleaning log documenting each step taken, including Power Query operations and calculated columns.
  
- **IMDb_Top_1000_Movie_Analysis_Worksheet_James_Nuccini.xlsx**  
  Excel workbook containing cleaned data, pivot tables, and five analysis charts.

## 📊 Charts and Visual Insights

1. **Most Common Genres** – Bar chart showing genre frequency.
2. **Average IMDb Rating by Genre** – Compares ratings across genres.
3. **Average Rating by Decade** – Line chart tracking rating trends over time.
4. **Top Directors by Average Rating** – Filters for directors with 3+ movies.
5. **IMDb Rating vs Number of Votes** – Scatterplot exploring popularity vs rating.

## 📊 Dataset Source

The dataset used in this project was sourced from [Kaggle](https://www.kaggle.com/datasets/bansodesandeep/imdb-top-1000-movies).

## 🧼 Tools & Techniques Used

- **Microsoft Excel**
- **Power Query** (for genre splitting and transformations)
- **Pivot Tables & Charts**
- **Basic Excel Formulas** (`=INT(Year/10)*10` for decade grouping)

## 🔍 Key Findings

- Drama is the most represented genre in the Top 1000.
- Ratings across genres are tightly clustered (~7.9–8.0).
- The 1920s and 2020s had the highest average ratings (8.13).
- Christopher Nolan had the highest average IMDb rating (min. 3 films).
- No strong correlation between rating and vote count, but high-vote films tend to be well-rated.
